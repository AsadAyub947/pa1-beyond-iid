# Report

Put the final 8-page NeurIPS-format PDF here as `report.pdf` (and, if you like, its LaTeX sources).

`figures/` holds the figures used in the report, copied unchanged from the task result folders:

| File prefix | Source |
|---|---|
| `t1_*` | `task1/results/plots/` |
| `t2_*` | `task2/results/plots/` |
| `t3_*` | `task3/results/plots/` |
| `t4_*` | `task4/results/` |

Regenerate them by re-running each task's evaluation script (see the top-level README); never edit them by hand.
